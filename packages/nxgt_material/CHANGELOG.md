## 0.3.0

Adds the `dates.dart` library and three fields: `SwitchField`, `UrlField` and `OtpField`.

### Breaking

- `NxgtMaterialLocalizations` gains the getters `datesClear`, `datesBefore`, `datesAfter`, `datesRangeValue`, `fieldsInvalidUrl` and `fieldsOtpIncomplete`. Only a class that implements or extends `NxgtMaterialLocalizations` directly no longer compiles; extend `NxgtMaterialLocalizationsWrapper` instead, which forwards every string. Apps that only use the delegate, `context.materialL10n` or a `reword:` subclass of the wrapper are not affected.

### Fixed

- `OtpField`: pasting a full code over typed digits no longer gives a wrong code (`654321` pasted after `12` gave `126543` and fired `onCompleted` with it), and pasting into a full field now replaces the code instead of doing nothing. A pasted or autofilled chunk holding `length` digits or more becomes the code.
- `DateField` and `DateRangeField` assert in debug that `lastDate` is not before `firstDate` (a release build reads it as `lastDate == firstDate`); `DateRangeField` words the bound in its range error through its `formatter`, like `DateField`, instead of always the locale's medium date.
- `Validators.url` and `UrlField` accept hosts with combining marks, such as `मेरा.भारत`.
- `SwitchField` and `CheckboxField` no longer let a screen reader read the helper text twice, once as the control's hint and once as separate text.
- The French `datesAfter` message uses a typographic apostrophe.

### Added

- `fields.dart`: `OtpField` gains `autovalidateMode`.

- `selection.dart`: `SwitchField` (a `FormField<bool>` on a full-width `SwitchListTile` at least 48 dp high, off by default; a `validator` expresses "must be on", the error has the `alert` role and replaces the helper text, which with the error is the switch's semantics hint; works with `Form` validate, save and reset and with `autovalidateMode`; directional layout). Reuses the strings of the other choice fields; no new string.

- `dates.dart`: `DateRangeField` (a range of dates as a read-only field that opens `showDateRangePicker` with its calendar and typed-entry toggle: Flutter's `DateTimeRange` value with both ends at midnight, text and spoken value "start to end" from `MaterialLocalizations.formatMediumDate` or a `formatter`, `firstDate` and `lastDate` naming the bound in an error, `required`, `clearable` with a 48 dp clear button, one semantics node). New string `datesRangeValue` in fr and en.
- `dates.dart`: `TimeField` (a time of day as a read-only field that opens `showTimePicker` with its dial and typed-entry toggle: `TimeOfDay` value, text from `MaterialLocalizations.formatTimeOfDay` or a `formatter`, `use24HourFormat` to force the 12 or 24 hour clock in the text and the picker (`null` follows `MediaQuery.alwaysUse24HourFormat`), `required`, `clearable` with a 48 dp clear button, one semantics node). Reuses the `datesClear` string.
- `dates.dart` (new library): `DateField` (a date as a read-only field that opens `showDatePicker` with its calendar and typed-entry toggle: `DateTime` at midnight, text from `MaterialLocalizations.formatMediumDate` or a `formatter`, `firstDate` and `lastDate` clamping the picker and naming the bound in an error, `required`, `clearable` with a 48 dp clear button, one semantics node with the error or helper text as its hint). New strings `datesClear`, `datesBefore` and `datesAfter` in fr and en.
- `fields.dart`: `OtpField` (a one-time code as one real input with invisible text over `length` 48 dp slots: native paste stripped to digits and cut at `length`, `AutofillHints.oneTimeCode`, one semantics node, slots left to right in RTL; `onCompleted` fires once per completion and never submits the form; built-in incomplete and `required` checks). New string `fieldsOtpIncomplete` in fr and en.
- `fields.dart`: `UrlField` (URL keyboard, `url` autofill, no capitalization, autocorrect off, `required`, `textInputAction`; keeps the text as typed) and `UrlField.normalize` (trims, adds `https://` when there is no scheme, `null` when invalid). `Validators.url()` accepts http and https addresses with a dotted host and an optional scheme. New string `fieldsInvalidUrl` in fr and en.

## 0.2.0

Adds four libraries: `display.dart`, `overlays.dart`, `selection.dart` and `collections.dart`.

### Breaking

- `EmailField`, `PasswordField`, `NumberField`, `PhoneField` and `TextAreaField` now extend the internal, unexported `TextFieldBase`. Code that relied on their previous superclass or on members outside their documented constructor needs updating; their constructors are unchanged.
- `PasswordField` is now a `StatelessWidget` (its visibility toggle lives in a private widget). Code that reached its `State` must stop doing so.
- `NxgtMaterialLocalizations` gains the new strings listed below. A class that implements or extends `NxgtMaterialLocalizations` directly no longer compiles; extend `NxgtMaterialLocalizationsWrapper` instead, which forwards every string.

### Added

- `display.dart`: `StatusIndicator` (a dot or the tone icon and a label in AA tone colours from `FeedbackTone`, the tone spoken first) and `CountBadge` (a count on `Badge.count`: `99+` above `max`, hidden at 0, spoken with a plural label; asserts a negative count and a non-positive `max`). New string `displayCount` in fr and en.
- `display.dart`: `UserAvatar` (a `CircleAvatar` with the picture or the name's initials, also when the image fails, on a theme tone picked from the name with AA contrast, an optional `AvatarPresence` dot spoken after the name; an empty name draws a person icon; asserts a non-positive `size`). New strings `displayPresenceOnline`, `displayPresenceAway`, `displayPresenceBusy`, `displayPresenceOffline` in fr and en.
- `display.dart`: `StatCard` (a key figure on a `Card`: label, value, a `delta` pill tinted by `StatTrend` up, down or flat with AA tone colours, `positiveIsUp` to swap the tones for a cost, an optional decorative icon; one merged semantics node that speaks the trend word, never colour alone; with `onTap` a 48 dp button with `InkWell` focus and hover, without it not focusable; directional layout). New strings `displayTrendUp`, `displayTrendDown`, `displayTrendFlat` in fr and en.
- `display.dart`: `DescriptionList` and `DescriptionItem` (labels and values as rows, side by side from the medium window size and stacked on compact through `context.windowSize`; `copyable` adds a `CopyButton` labelled with the item; each row is one node read as "label, value", labels are not headings; directional layout; an empty list draws nothing). New string `actionsCopyItem` ("Copy {label}") in fr and en.
- `display.dart`: `EntityHeader` and `EntityAction` (a record page heading: a title that is a semantics header, a muted subtitle, a `leading` widget such as `UserAvatar`, a `status` widget such as `StatusIndicator`, and actions drawn as buttons from the medium window size and as a menu on compact or above 1.5x text scale; a `destructive` action uses the error tone; long text wraps; directional layout; asserts an empty title and an empty action label). Reuses the string `actionsMoreOptions`; no new string.
- `overlays.dart`: `ConfirmDialog` and `context.confirm` (an `AlertDialog` at every window size that returns `true` on confirm and `false` on cancel, Escape, barrier tap or back; the confirm action runs an optional async `onConfirm` through `AsyncButton` with a busy state, keeps the dialog open and reports the error when it throws; `destructive` uses the error tone with AA contrast and starts the focus on Cancel; 48 dp targets, scrollable message, directional layout; asserts an empty title). `AsyncButton` gains `autofocus`. New strings `actionsCancel` and `actionsConfirm` in fr and en.
- `overlays.dart`: `context.showAdaptiveSheet` and `AdaptiveSheet` (a modal sheet chosen by window size, not platform: a bottom sheet with a drag handle, safe area, keyboard inset and 90 % maximum height on compact, a 400 dp side sheet on the end edge, RTL-aware, from medium up; returns the popped value or `null` on the close button, Escape, barrier or back; the title is a semantics header that names the route; scrolling body; 48 dp close button; asserts an empty title). Reuses the string `actionsClose`; no new string.
- `overlays.dart`: `FormDialog` and `context.showFormDialog` (a form in a dialog chosen by window size: full-screen with a top app bar holding the close button, the title and the submit action on compact, a dialog up to 560 dp wide with Cancel and the submit action from medium up; wraps the content in a `Form` with a `SubmitButton` that validates, shows a busy state and pops the value `onSubmit` returns, keeps the dialog open and reports the error when it throws; locked while submitting, also during the exit animation; once a field changed, closing by the close button, Cancel, Escape, barrier or back asks "Discard changes?" through `context.confirm(destructive: true)`, a clean dialog closes at once with `null`; the title is a semantics header that names the route once; 48 dp targets, keyboard-safe scrolling, reduced motion, directional layout; asserts an empty title). New strings `overlaysDiscardTitle`, `overlaysDiscardMessage` and `overlaysDiscardConfirm` in fr and en.
- `selection.dart`: `CheckboxField` (a `FormField<bool>` on a full-width `CheckboxListTile` at least 48 dp high under any density, label tappable; `required` means checked, `validator` runs after it, `helperText` is replaced by the error, which has the `alert` role and a live region off the web; works with `Form` validate, save and reset and with `autovalidateMode`; directional layout, wraps at large text sizes). The internal `ChoiceFieldBase<T>` it extends, unexported like `TextFieldBase`, is the base of the other choice fields too. Reuses the string `fieldsRequired`; no new string.
- `selection.dart`: `RadioGroupField<T>` (a `FormField<T?>` on Flutter's `RadioGroup`) and `CheckboxGroupField<T>` (a `FormField<Set<T>>` that reports new unmodifiable sets), with the public `ChoiceOption<T>` (`value`, `label`, `description`, `enabled`) shared by the radio, checkbox, chips and select fields. A visible group label that is also the name of a container node holding one node per option, with the error or helper text as its hint; 48 dp tiles, arrow keys inside the radio group, `required`, disabled field and disabled options, directional layout, wrapping at large text sizes. `ChoiceFieldBase` gains the internal `isGroup` hook. Reuses `fieldsRequired`; no new string.
- `selection.dart`: `ChoiceChipsField<T>` (a `FormField<T?>` on Material 3 `ChoiceChip`s; radio-like semantics; tapping the chosen chip again clears it unless `required`) and `FilterChipsField<T>` (a `FormField<Set<T>>` on `FilterChip`s, reporting new unmodifiable sets in option order), two classes so each value type stays sound. Chips wrap, are padded to 48 dp on every platform, are reached by Tab and toggled by Space and Enter; `ChoiceOption.description` is the chip's tooltip. Same group semantics, `required`, disabled field and options, `focusNode` rule and directional layout as the other choice fields. Reuses `fieldsRequired`; no new string.
- `selection.dart`: `SelectField<T>` (a `FormField<T?>` around Material 3 `DropdownMenu`, which is not a form field; a field-like control filling the parent width with the label as `DropdownMenu`'s label; on a compact window with `searchable` or more than 12 options a tap opens `context.showAdaptiveSheet` with a case- and accent-insensitive search box and 48 dp option tiles, otherwise the menu, filtering when `searchable`). Disabled options are shown and not chosen, `ChoiceOption.description` is a second line, `required` or a clear button back to `null`, the error and helper text are the hint of the control and drawn once by the base footer, Enter or Space opens the menu. New strings `selectionClear` ("Clear selection" / "Effacer le choix") and `selectionNoResults` ("No results" / "Aucun résultat", shown as a live region when the sheet's search matches nothing) in both ARBs and `NxgtMaterialLocalizationsWrapper`. The sheet's search box reuses `collectionsSearchHint`.
- `collections.dart`: `SearchField` (a search input that is not a `FormField`: a search icon, a localized hint, a 48 dp clear button shown only when there is text that emits `''` at once and keeps the focus, the `search` keyboard action, and `onChanged` debounced by `debounce`, 300 ms by default, `Duration.zero` for every keystroke; `onSubmitted` fires at once and drops a pending emission; no callback after dispose; owns its controller and focus node only when none is given, follows a swapped controller; the node is a text field of the search input type; directional layout; asserts `controller` with `initialValue`, and a negative `debounce`). New strings `collectionsSearchHint` ("Search" / "Rechercher") and `collectionsSearchClear` ("Clear search" / "Effacer la recherche") in both ARBs and `NxgtMaterialLocalizationsWrapper`.
- `collections.dart`: `PagedList<T>` and `LoadMoreMode` (a vertical list loaded page by page: the first load, the failure and the empty state through `AsyncView`'s `LoadingState`, `ErrorState` and `EmptyState`; a `LoadMoreButton` at the end or, with `LoadMoreMode.onScroll`, `onLoadMore` within about one viewport of the end, never while a call runs and not repeated for a load that added nothing; a failing `onLoadMore` is reported, shows an inline `ErrorState` with a retry and stops auto-loading until it succeeds; `loading` and `error` also drive the end of the list for a caller-run load; pull to refresh through `RefreshIndicator`; "N more loaded" announced as a `status` node, a live region off the web; optional separators and padding; a `ScrollController` never disposed, owned only when none is given; 48 dp controls under desktop density, directional layout, reduced motion; no `shrinkWrap` or sliver variant; asserts `hasMore` without `onLoadMore`). New strings `collectionsSortBy`, `collectionsSortedAscending` and `collectionsSortedDescending` ("Sort by", "{column}, sorted ascending", "{column}, sorted descending" / "Trier par", "{column}, tri croissant", "{column}, tri décroissant") in both ARBs and `NxgtMaterialLocalizationsWrapper`.

### Fixed

- `AsyncButton`, `LoadMoreButton`, `CopyButton`, `SplitButton` (the main part and the arrow), the close button of `InlineAlert`, the toggle of `PasswordField` and the menu and drawer close buttons of `AdaptiveShell` keep a 48 dp target on desktop platforms (all four `AsyncButton` variants, busy or not), instead of the 32 dp of desktop density. These buttons now force padded tap targets and standard density over an app's button theme.

## 0.1.0

First release.

- `theme.dart`: `ThemeSpec` builds a Material 3 light and dark `ThemeData` from a seed colour (`ColorScheme.fromSeed`), with the 14 presets of `@nxgt/material` (`ThemePresets`), AA-solved `Tones` (primary, secondary, tertiary, success, info, warning, error, neutral, and app tones), `RadiusScale`, `ThemeFonts` and `ThemeMotif` as `ThemeExtension`s, `context.tones` / `radii` / `fonts` / `motif`, and a `TokenSheet` widget. `context.tones` falls back to `Tones.fromScheme` of the theme's colour scheme (cached per scheme) and `context.radii` to the Material 3 Expressive defaults; `context.fonts` and `context.motif` fall back to `const ThemeFonts()` and `ThemeMotif.none`; `Tones.operator []` returns `ToneColors?`.

- `l10n.dart`: French and English strings (`gen-l10n`, ARBs in `lib/l10n/`) for actions, field validation, feedback states and adaptive navigation. `NxgtMaterialLocalizationsDelegate` (falls back to English for any other locale, takes `reword:` to override strings through a `NxgtMaterialLocalizationsWrapper` subclass), `NxgtMaterialLocalizations.supportedLocales` and `context.materialL10n`. Widgetbook gets a locale addon.

- `actions.dart`: `AsyncButton` (a Material 3 button whose async action shows a spinner and ignores presses until done, four variants), `CopyButton` (copies a value, shows a check mark, announced to screen readers), `SplitButton` (main action plus a `MenuAnchor` of related actions) and `LoadMoreButton` (an outlined `AsyncButton` for paginated lists). New strings `actionsCopy`, `actionsCopied`, `actionsMoreOptions` in fr and en.

- `fields.dart`: `EmailField`, `PasswordField` (show/hide toggle), `PhoneField`, `NumberField` and `TextAreaField`, built on `TextFormField` with the right keyboard, autofill hints and input action, and `Validators` (`required`, `email`, `minLength`, `maxLength`, `phone`, `number`, `compose`) with localized messages; `NumberField.parse` is the public number parser. `forms.dart`: `FormSection` and `SubmitButton` (validates, saves and awaits an action through `AsyncButton`; asserts it is inside a `Form`). New strings `fieldsInvalidPhone`, `fieldsInvalidNumber`, `fieldsMinValue`, `fieldsMaxValue`, `fieldsShowPassword`, `fieldsHidePassword` in fr and en.

- `feedback.dart`: `EmptyState`, `LoadingState` (a static icon under reduced motion), `ErrorState` (retry through `AsyncButton`), `AsyncView<T>` (switches between them and your content over a `Future` or an `AsyncSnapshot`, with an `errorBuilder`; a failed future is reported once), `InlineAlert` and `FeedbackTone` (info, success, warning, error; role `alert` or `status`, tone spoken first, AA tone colours) and `context.showToast` (a tinted, announced `SnackBar` with an optional action). New strings `feedbackToneInfo`, `feedbackToneSuccess`, `feedbackToneWarning`, `feedbackToneError` in fr and en. `EmptyState` and `LoadingState` have the semantics role `status`, `ErrorState` the role `alert`; on the web the role alone is announced, elsewhere a live region speaks, so each is announced once. `context.showToast` comes from the `ToastContext` extension; `InlineAlert.icon` is a `Widget?`.

- `layout.dart`: `WindowSize` and `Breakpoints` (the Material 3 classes, 600 / 840 / 1200 / 1600, shared with `@nxgt/material`) with `context.windowSize`; `AdaptiveShell` (a `NavigationBar` on compact or a modal drawer with `CompactNavigation.drawer`, a `NavigationRail` on medium, a standing `NavigationDrawer` on expanded and wider; safe areas, focus traversal and hover kept) with `ShellDestination`; `PageBody` (maximum width and gutters per window size); `ResponsiveGrid` (columns by minimum tile width); `ListDetailLayout` (two panes above 648 dp, one below, back gesture calls `onBack`). `AdaptiveShell` asserts two destinations or more and `selectedIndex` in range, forwards `appBar`, `actions`, `bottomSheet` and `floatingActionButtonLocation`, keeps the body's state across size classes, honours the text direction for safe areas and closes an open drawer when the window leaves compact; `ListDetailLayout` keeps both panes' state across 648 dp. New string `layoutNavigation` in fr and en. Guide: `doc/guide/adaptive.md`.

- Package: guides, component pages and troubleshooting in `doc/`, `topics`, a `.pubignore`, `intl ^0.20.3`. A category library appears with its first component: 0.1 ships `actions`, `feedback`, `fields`, `forms`, `layout`, `theme` and `l10n`, plus the barrel `nxgt_material.dart`.
